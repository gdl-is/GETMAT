Come installare e verificare curl su Windows

Una guida per assicurarsi che curl sia configurato correttamente per i tuoi script Batch.

Passo 0: Verifica preliminare (Windows 10/11)

Le versioni recenti di Windows includono già curl di serie.

Prima di scaricare file, apri il Prompt dei comandi e digita:

curl --version
✅ Se ricevi una risposta con il numero della versione, non devi fare altro!

Passo 1: Scaricare i file (Versioni precedenti)

Se il comando non viene riconosciuto, vai su curl for Windows.

Scarica il pacchetto ZIP adatto alla tua architettura (solitamente 64-bit).

Passo 2: Posizionamento

Estrai il file ZIP. Troverai una cartella chiamata bin contenente curl.exe.

Crea una cartella in C:\curl e copia al suo interno il contenuto della cartella estratta.

💡 Assicurati che il file curl.exe si trovi esattamente in C:\curl\bin\curl.exe.

Passo 3: Aggiungere curl al PATH

Per usare curl ovunque, aggiungiamolo alle variabili di sistema:

  1. Premi il tasto Start e scrivi "Variabili di ambiente".
  2. Scegli "Modifica le variabili di ambiente relative al sistema".
  3. Clicca su Variabili d'ambiente....
  4. Sotto "Variabili per l'utente", seleziona Path e clicca su Modifica.
  5. Clicca su Nuovo e inserisci:
    C:\curl\bin
  6. Clicca OK su tutte le finestre.

Passo 4: Test finale

Riavvia il terminale e digita:

curl --version

Ora sei pronto per eseguire i tuoi script di download automatico!
